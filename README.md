# ReText legacy browser recovery — public repository
This repository is only the recovery page for existing users of
https://trump2020eth.github.io/Retext/ .
No editor source code, payment service, licenses or user images are hosted here.
The page reads backups from the visitor's own browser storage at the same origin.
Do not rename the new repository to `Retext` until the original source repository
has safely been renamed and protected.
In GitHub Settings > Pages, set Source to **GitHub Actions**.
