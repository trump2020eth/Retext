# ReText legacy browser recovery — public repository
This repository is only the recovery page for existing users of
https://trump2020eth.github.io/Retext/ .
No editor source code, payment service, licenses or user images are hosted here.
The page reads backups from the visitor's own browser storage at the same origin.
Do not rename the new repository to `Retext` until the original source repository
has safely been renamed and protected.
In GitHub Settings > Pages, set Source to **GitHub Actions**.

## Current Retext product

**Retext** is a browser-based image text editor for making authorized wording changes in JPG and PNG images when the original design file is unavailable. Try two free downloads before deciding whether to unlock additional downloads with a one-time payment.

- [Use Retext online](https://retext-editor.pages.dev/)
- [How to change text in a JPG or PNG](https://retext-editor.pages.dev/how-to-edit-text-in-image.html)
- [Fix short wording changes on product graphics](https://retext-editor.pages.dev/edit-product-image-text.html)

The editor's production source is private and is **not** stored in this public recovery repository. For exact fonts or complex backgrounds, inspect each exported result and prefer the original layered design file where possible.
